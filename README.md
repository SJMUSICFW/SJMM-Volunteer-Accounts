# St. Jude Music Ministry Volunteer Accounts

A responsive volunteer portal prototype for individuals and whole families.

## Included

- Volunteer ID, email, or phone login
- User-created and editable Volunteer IDs
- One household account with individual adult and child profiles
- Multiple email addresses and phone numbers on one account
- Required phone-number explanation and communication consent
- Household-wide sign-up tracking
- Personalized volunteer opportunity suggestions
- Responsive desktop and mobile layouts
- Local browser persistence for prototype accounts and sign-ups

## Preview

Open `index.html` in a browser. Select **Preview a sample account** to explore the dashboard, or create a new local prototype account.

This repository currently provides a front-end prototype. A production release should connect the forms to a secure authentication service and database rather than browser storage.
